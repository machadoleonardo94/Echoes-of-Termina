Place your .echoes project files here.

A project file keeps every track in its own [TrackName] section, so it stays
readable and each track reopens as a selectable slot in the editor.

The mask firmware plays a single time-ordered stream, so it uses a separate
file: "Export to Mask" (Ctrl+E) merges all tracks into one .echoes script for
the SD card, and "Upload Project" sends a merged copy to the device.
